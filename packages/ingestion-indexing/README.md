# @contextctl/ingestion-indexing

Source ingestion, document indexing, and managed document retrieval for Contextctl.

This package is part of the [Contextctl monorepo](https://github.com/TEAM-SEAM-contextctl/contextctl). Most users should install `@contextctl/daemon`, which provides the complete command-line and service composition.

The supported public surface is the package root export. Internal source paths and physical index bindings are not public contracts.
