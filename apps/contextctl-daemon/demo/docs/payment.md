# 결제 운영 규정

이 문서는 주문 결제의 승인, 결제 실패 시 재시도, 결제 수단, 카드 한도, 부분 결제, PG 오류 코드 처리 기준을 정합니다. 환불은 별도 환불 규정을 따릅니다.

## 결제 승인

결제 승인은 고객이 결제 버튼을 누른 시점부터 최대 60초 안에 완료되어야 합니다. PG사의 승인 응답이 60초를 초과하면 해당 결제는 승인 대기 상태로 두고, 승인 여부를 5분 안에 다시 확인합니다. 승인 대기 상태의 주문은 재고를 15분 동안 임시 확보합니다.

- 승인이 완료되면 고객에게 결제 완료 알림을 즉시 발송합니다.
- 동일 주문에 대한 중복 승인은 시스템이 자동으로 차단합니다.
- 승인 금액과 주문 금액이 다르면 승인을 자동 취소하고 결제 실패로 처리합니다.

## 결제 실패와 재시도

결제 실패는 최대 세 번까지 재시도합니다. 재시도 간격은 5분, 30분, 2시간입니다. 세 번 모두 실패하면 주문은 자동으로 취소되고 고객에게 알림이 발송됩니다.

| 재시도 회차 | 실패 후 대기 시간 | 실패 시 처리 |
| --- | --- | --- |
| 1회차 | 5분 | 2회차 재시도 예약 |
| 2회차 | 30분 | 3회차 재시도 예약 |
| 3회차 | 2시간 | 주문 자동 취소, 고객 알림 |

> 재시도는 정기 결제와 자동 결제에만 적용되며, 고객이 직접 진행하는 일회성 결제는 실패 즉시 결제 화면으로 돌아갑니다.

## 결제 수단

지원하는 결제 수단은 신용카드, 체크카드, 계좌이체, 간편결제, 가상계좌의 다섯 가지입니다. 결제 수단은 주문당 하나만 선택할 수 있으며, 가상계좌는 발급 후 24시간 안에 입금하지 않으면 주문이 자동 취소됩니다.

- 신용카드와 체크카드: 5만 원 이상 결제 시 무이자 할부 3개월까지 가능
- 계좌이체: 1회 결제 한도 500만 원
- 간편결제: 등록된 카드 또는 계좌로 즉시 결제
- 가상계좌: 입금 마감 24시간, 입금 확인 후 결제 완료 처리

## 카드 한도 초과 처리

카드 한도 초과로 결제 승인이 거절되면 재시도하지 않고 고객에게 다른 결제 수단을 안내합니다. 카드 한도 초과는 카드사 응답 코드로 식별하며, 동일 카드로 24시간 안에 3회 이상 한도 초과가 발생하면 해당 카드는 당일 결제 시도가 제한됩니다.

## 부분 결제

부분 결제는 한 주문의 금액을 포인트와 다른 결제 수단으로 나누어 결제하는 방식입니다. 포인트는 주문 금액의 최대 50%까지 사용할 수 있고, 나머지 금액은 하나의 결제 수단으로 결제합니다. 부분 결제에서 결제 수단 승인이 실패하면 사용한 포인트는 즉시 원상 복구됩니다.

1. 고객이 사용할 포인트 금액을 입력합니다.
2. 시스템이 포인트 사용 상한(주문 금액의 50%)을 검증합니다.
3. 잔여 금액에 대해 선택한 결제 수단으로 승인을 요청합니다.
4. 승인 성공 시 포인트 차감과 결제 완료를 동시에 확정합니다.
5. 승인 실패 시 포인트를 복구하고 결제 실패 안내를 표시합니다.

## PG 오류 코드

PG 오류 코드는 다음 표의 기준에 따라 처리하며, 재시도 대상 코드만 자동 재시도합니다. 표에 없는 오류 코드는 결제 실패로 처리하고 운영팀이 당일 확인합니다.

| 오류 코드 | 의미 | 처리 방식 |
| --- | --- | --- |
| PG-1001 | PG 응답 시간 초과 | 자동 재시도 |
| PG-1002 | 카드 한도 초과 | 재시도 없음, 다른 결제 수단 안내 |
| PG-1003 | 카드 유효기간 만료 | 재시도 없음, 카드 정보 갱신 안내 |
| PG-1004 | 비밀번호 오류 | 재시도 없음, 고객 재입력 안내 |
| PG-2001 | PG 시스템 점검 | 점검 종료 후 자동 재시도 |

## 예외 규정

- 결제 금액이 100만 원을 초과하는 주문은 자동 재시도 대상에서 제외하고 운영팀이 수동으로 처리합니다.
- PG사 점검 시간(매일 00:00부터 00:30까지)에 발생한 결제 실패는 재시도 횟수에 포함하지 않습니다.
- 해외 발급 카드는 부분 결제와 무이자 할부를 지원하지 않습니다.
- 동일 고객이 1시간 안에 10회 이상 결제 실패를 반복하면 부정 거래 검토를 위해 결제를 일시 제한합니다.
