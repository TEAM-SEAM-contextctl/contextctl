# 배송 운영 규정

이 문서는 배송 조회, 운송장 번호 발급, 배송 소요 기간, 배송비, 배송 지연, 도서산간 배송, 분실·파손 처리 기준을 정합니다.

## 배송 조회

배송 조회는 운송장 번호를 사용합니다. 운송장은 출고 후 2시간 이내에 발급됩니다. 운송장 번호가 발급되면 고객에게 알림이 발송되고, 주문 상세 화면의 배송 조회 버튼에서 택배사 배송 현황을 실시간으로 확인할 수 있습니다.

- 배송 조회 상태는 출고 완료, 집하, 간선 이동, 배송 출발, 배송 완료의 5단계로 표시됩니다.
- 택배사 시스템 반영은 집하 후 최대 12시간이 걸릴 수 있습니다.
- 운송장 번호는 출고일로부터 90일 동안 조회할 수 있습니다.

## 배송 소요 기간

일반 배송은 출고일 기준 1~2영업일, 도서산간 지역은 3~5영업일이 걸립니다. 평일 14:00 이전 주문은 당일 출고하고, 14:00 이후 주문과 주말·공휴일 주문은 다음 영업일에 출고합니다.

| 배송 유형 | 출고 기준 | 소요 기간 |
| --- | --- | --- |
| 일반 배송 | 평일 14:00 이전 주문 당일 출고 | 출고 후 1~2영업일 |
| 새벽 배송 | 전날 22:00 이전 주문 | 다음 날 07:00 이전 |
| 도서산간 배송 | 당일 또는 다음 영업일 출고 | 출고 후 3~5영업일 |
| 예약 배송 | 고객 지정일 2일 전 출고 | 고객 지정일 |

## 배송비

기본 배송비는 3,000원이며, 주문 금액 5만 원 이상이면 배송비가 무료입니다. 도서산간 지역은 기본 배송비에 추가 배송비 3,000원에서 6,000원이 부과되며, 추가 배송비는 무료 배송 조건에 관계없이 청구됩니다.

| 구분 | 배송비 |
| --- | --- |
| 주문 금액 5만 원 미만 | 3,000원 |
| 주문 금액 5만 원 이상 | 무료 |
| 제주 지역 추가 배송비 | 3,000원 |
| 그 외 도서산간 추가 배송비 | 6,000원 |
| 새벽 배송 | 주문 금액과 관계없이 2,000원 |

## 배송 지연 안내

천재지변이나 물류 파업으로 지연되면 고객에게 사전 안내를 발송합니다. 출고 후 3영업일이 지나도 배송 완료되지 않은 주문은 배송 지연으로 분류하고, 운영팀이 택배사에 확인하여 1영업일 안에 고객에게 예상 도착일을 안내합니다.

> 명절 연휴 전후 3영업일과 연말 성수기(12월 20일부터 12월 31일까지)에는 배송이 평소보다 1~2영업일 더 걸릴 수 있으며, 주문 화면에 지연 가능 안내를 표시합니다.

- 배송 지연이 7영업일을 초과하면 고객에게 배송비 전액을 포인트로 보상합니다.
- 택배사 사유로 인한 배송 지연 보상은 택배사 확인서를 근거로 처리합니다.

## 도서산간 배송

도서산간 지역은 제주, 울릉도, 그 외 섬 지역과 산간 오지로 구분하며, 주소 입력 시 우편번호로 자동 판별됩니다. 도서산간 지역은 새벽 배송과 예약 배송을 지원하지 않고, 냉장·냉동 상품은 배송이 제한됩니다.

- 제주 지역: 출고 후 2~3영업일, 추가 배송비 3,000원
- 울릉도 및 기타 섬 지역: 출고 후 3~5영업일, 추가 배송비 6,000원
- 산간 오지: 택배사 배송 가능 여부에 따라 출고 전 고객센터가 개별 안내

## 분실·파손 접수 절차

배송 조회 상태가 배송 완료인데 상품을 받지 못했거나 파손된 상태로 받은 경우, 배송 완료 표시일로부터 3일 안에 고객센터에 접수해야 합니다. 접수 후 택배사 조사를 거쳐 분실 또는 파손이 확인되면 동일 상품을 재발송합니다.

1. 고객센터에 주문 번호와 운송장 번호를 알리고 분실 또는 파손을 접수합니다.
2. 파손의 경우 상품과 포장 상태 사진을 접수 시 함께 제출합니다.
3. 택배사가 접수일로부터 3영업일 안에 배송 기사 확인과 현장 조사를 진행합니다.
4. 분실 또는 파손이 확인되면 1영업일 안에 동일 상품을 재발송합니다.
5. 재고가 없으면 고객센터가 대체 상품 또는 다른 처리 방법을 안내합니다.

## 예외 규정

- 고객이 입력한 주소 오류로 반송된 주문은 재배송 시 배송비 3,000원을 고객이 부담합니다.
- 경비실, 택배함 등 고객이 지정한 장소에 배송 완료된 이후의 분실은 택배사 조사 대상에서 제외됩니다.
- 냉장·냉동 상품은 배송 완료 후 당일 안에 파손을 접수한 경우에만 재발송합니다.
- 태풍, 폭설 등 기상 특보 발효 지역은 특보 해제 시까지 출고를 보류하고 배송 지연 안내를 발송합니다.
