# @contextctl/registry-lifecycle

Context Card generation, approval, lineage, versioning, and lifecycle management for Contextctl.

This package is part of the [Contextctl monorepo](https://github.com/TEAM-SEAM-contextctl/contextctl). Most users should install `@contextctl/daemon`, which provides the complete command-line and service composition.

The supported public surface is the package root export. Internal persistence models are not public contracts.
