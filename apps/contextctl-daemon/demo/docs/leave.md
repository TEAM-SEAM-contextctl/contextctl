# 인사 규정: 휴가

이 문서는 임직원의 연차, 반차, 병가, 경조휴가의 부여 기준과 휴가 신청 절차를 정합니다. 휴가 관련 문의는 인사팀으로 합니다.

## 연차 부여 기준

연차는 입사 1년 후 15일이 부여됩니다. 입사 1년 미만인 직원은 1개월 개근할 때마다 연차 1일이 발생하며, 첫해에는 최대 11일까지 사용할 수 있습니다. 근속 3년 차부터는 2년마다 연차 1일이 가산되고, 가산을 포함한 연차 상한은 25일입니다.

| 근속 기간 | 부여되는 연차 |
| --- | --- |
| 입사 1년 미만 | 매월 개근 시 1일 (최대 11일) |
| 1년 이상 3년 미만 | 15일 |
| 3년 이상 5년 미만 | 16일 |
| 5년 이상 7년 미만 | 17일 |
| 21년 이상 | 25일 (상한) |

> 연차 부여 기준일은 매년 1월 1일이며, 연중 입사자는 입사일 기준으로 비례 계산합니다.

## 반차

반차는 오전 반차와 오후 반차로 나뉘며 연차 0.5일을 차감합니다. 오전 반차는 09:00부터 13:00까지, 오후 반차는 14:00부터 18:00까지 자리를 비우는 것으로 처리합니다. 반차는 하루에 한 번만 사용할 수 있고, 같은 날 오전 반차와 오후 반차를 함께 쓰면 연차 1일로 처리됩니다.

- 반차는 사용일 전날 18:00까지 신청합니다.
- 반차 사용일에는 점심시간을 근무시간에 포함하지 않습니다.
- 반차를 4회 사용하면 연차 2일이 차감됩니다.

## 휴가 신청 절차

연차와 반차는 사용일 최소 3영업일 전에 인사 시스템으로 신청해야 합니다. 5일 이상 연속으로 사용하는 장기 휴가는 2주 전에 신청합니다.

1. 인사 시스템에서 휴가 종류(연차, 반차, 병가, 경조휴가)를 선택합니다.
2. 사용일과 잔여 연차를 확인하고 사유를 입력합니다.
3. 부서장이 신청일로부터 2영업일 안에 승인 또는 반려합니다.
4. 승인 완료 후 팀 캘린더에 자동 등록됩니다.
5. 사용일 변경이 필요하면 기존 신청을 취소하고 다시 신청합니다.

## 잔여 연차와 이월

사용하지 않은 연차는 다음 해로 이월되지 않습니다. 잔여 연차는 매년 12월 31일에 소멸하며, 인사 시스템의 "내 휴가" 화면에서 언제든지 잔여 연차를 확인할 수 있습니다.

- 회사는 매년 7월 1일과 10월 1일에 잔여 연차를 서면으로 안내하고 사용을 촉진합니다.
- 연차 사용 촉진 안내를 받고도 사용하지 않은 잔여 연차는 보상하지 않습니다.
- 회사 사정으로 승인된 휴가가 취소된 경우에만 해당 일수를 다음 해로 이월합니다.

## 병가

병가는 연간 10일까지 유급으로 사용할 수 있습니다. 연속 3일을 초과하는 병가는 복귀일에 의료기관 진단서를 인사팀에 제출해야 하며, 10일을 초과하는 병가는 무급 처리됩니다.

| 병가 일수 | 급여 | 필요 서류 |
| --- | --- | --- |
| 1일에서 3일 | 유급 | 없음 |
| 4일에서 10일 | 유급 | 진단서 |
| 11일 이상 | 무급 | 진단서, 부서장 소견 |

## 경조휴가

경조휴가는 연차와 별도로 부여되며 잔여 연차를 차감하지 않습니다. 경조휴가는 사유 발생일로부터 30일 안에 사용해야 하고, 사용 후 7일 안에 증명 서류를 인사팀에 제출합니다.

| 사유 | 휴가 일수 |
| --- | --- |
| 본인 결혼 | 5일 |
| 자녀 결혼 | 1일 |
| 배우자 출산 | 10일 |
| 부모 또는 배우자 부모 사망 | 5일 |
| 형제자매 사망 | 3일 |

## 예외 규정

- 부서장 승인 없이 사용한 휴가는 결근으로 처리하고 연차를 차감하지 않습니다.
- 수습 기간 3개월 동안은 병가와 경조휴가만 사용할 수 있습니다.
- 연차 사용일에 긴급 호출로 4시간 이상 근무한 경우 해당 연차는 차감하지 않고 복원됩니다.
- 퇴직 예정자는 마지막 근무일 전에 잔여 연차를 모두 사용하는 것을 원칙으로 합니다.
