# @contextctl/selection-delivery

Context Card selection, retrieval-guide planning, and context delivery for Contextctl.

This package is part of the [Contextctl monorepo](https://github.com/TEAM-SEAM-contextctl/contextctl). Most users should install `@contextctl/daemon`, which provides the complete command-line and service composition.

The supported public surface is the package root export. Internal ranking and planning data are not public wire contracts.
