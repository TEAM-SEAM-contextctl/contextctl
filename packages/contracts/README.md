# @contextctl/contracts

Versioned lifecycle contracts shared across Contextctl package boundaries.

This package is part of the [Contextctl monorepo](https://github.com/TEAM-SEAM-contextctl/contextctl). Most users should install `@contextctl/daemon`, which provides the `contextctl` command and installs this package as a dependency.

The supported public surface is the package root export. Internal source paths are not part of the compatibility contract.
