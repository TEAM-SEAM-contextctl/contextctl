# 0014. 무관한 Card 증가가 선택 근거를 바꾸지 못하게 한다

- 상태: Accepted
- 날짜: 2026-08-26
- 범위: selection, daemon

## 맥락

`selection-lexical-v3`는 BM25와 선언 어휘 특이성을 전체 승인 Card 수와 전체 문서 빈도로
계산했다. 같은 질의와 같은 관련 Card를 두고도 무관한 Card를 추가하면 IDF와 특이성이 커졌고,
44개에서 보류된 Card가 128개에서 승인되는 현상이 재현됐다. 이 변화는 새로운 근거가 생긴
결과가 아니라 카탈로그 크기만 바뀐 결과다.

실제 생성 Card 44개와 Granite 경로를 다시 측정하자, 넓은 파생 어휘를 가진 여러 Card가 같은
일반어를 공유해 직접 근거와 의미 1위가 서로 다른 Card를 가리키는 경우도 확인됐다. 기존
11문항은 이 결함을 찾고 규칙을 정하는 데 사용됐으므로 보정 자료이며, 일반화 근거로 다시
보고할 수 없다.

## 결정

어휘 정책을 `selection-lexical-v4`, 혼합 정책을 `selection-hybrid-v4`로 올린다. 승인·거부
임계값과 `selection-ranking-v2`는 바꾸지 않는다.

BM25, 선언 빈도와 평균 길이의 상대 통계 모집단은 질의 토큰과 하나 이상 일치하는 Card로
한정한다. 점수 결과와 `consideredCount`에는 승인 카탈로그의 모든 Card를 그대로 남긴다.
문자 n-gram은 상대 통계를 사용하지 않고 항상 거부 영역 안의 순위 보조값으로 유지한다.
결합 전 간접 점수 `0.05` 미만은 카탈로그 크기와 무관하게 수치 순위만 남기고 감사 신호로
취급하지 않는다. 따라서 질의 어휘와 무관한 Card를 추가해도 기존 Card의 점수와 승인 집합이
변하지 않고, 큰 카탈로그의 우연한 문자 겹침마다 신호 배열·객체를 만들지 않는다. 같은 Card에
같은 낮은 순위값이 반복되면 불변 후보 객체 하나를 재사용하며 질의 문자열이나 토큰은 보관하지
않는다. 이 낮은 값은 숫자로 먼저 계산하고, 직접 또는 감사 가능한 간접 근거가 처음 발견된
Card에만 일치 집합과 필드 객체를 구성한다.

넓은 자동 생성 Card 사이에서는 질의와 일치한 선언 토큰 수가 유일하게 가장 많고 그 수가
3개 이상인 Card만 강한 직접 근거(`0.91`)를 얻는다. 별칭과 키워드에 같은 토큰이 중복돼도
한 번만 센다. 이 직접 근거가 있으면, 더 약한 어휘 근거를 가진 의미 1위는 차이가 작은
1위라는 이유만으로 승인되지 않는다. 다만 의미 1위가 2위와 `0.03` 이상 벌어지거나 코사인이
`0.90` 이상인 독립적인 의미 근거는 그대로 인정한다.

반대로 어휘 1위가 유일하고 점수가 `0.80` 이상 `0.85` 미만이며, 그 Card의 코사인이 `0.82`
이상이고 의미 1위와의 차이가 `0.02` 이하이면 두 순위의 합의로 승인선 `0.85`를 부여한다.
두 약한 점수를 더하지 않고, 어느 한 순위도 선두가 아니거나 합의 폭을 벗어나면 적용하지
않는다.

파생 키워드가 보존한 `되어`·`되는`·`되면`·`되고`·`되지`·`된` 활용형은 형태소 사전 없이
안전하게 제거할 수 있는 `되다` 계열만 같은 어간으로 정규화한다. 일반 한국어 스테밍으로
확장하지 않으며, 선언과 질의 양쪽에 같은 결정적 변환을 적용한다.

제품 경로 검사는 실제 생성 Card 44개를 기준으로 규칙을 정하거나 실패 원인을 확인한 보정
44문항과, 최종 정책을 동결한 뒤 한 번만 연 봉인 11문항을 분리한다. 두 집합 모두 필요한 Card
회수율 1.0, 허용하지 않은 Card 승인 0을 요구한다. 같은 질의를 카탈로그
44·46·58·64·105·128개에서 반복해 기존 점수와 승인 집합의 변화가 모두 0인지 함께 검사한다.

## 기각한 대안

- **전역 승인 임계값을 올린다**: 카탈로그 크기에 따라 점수가 달라지는 원인은 남고, 복합
  질의의 필요한 Card까지 함께 잃는다.
- **전체 카탈로그 IDF를 유지하고 크기별 보정값을 둔다**: 64·128 같은 경계마다 새로운
  불연속이 생기며, 무관한 Card가 근거를 바꾼다는 문제를 숨길 뿐이다.
- **의미 1위를 항상 승인한다**: 밀집된 Granite 코사인 분포에서 일반어가 많은 인접 Card를
  승인한다. 직접 근거와 충돌할 때 오선택을 되살린다.
- **보정에 쓴 질의를 홀드아웃으로 계속 보고한다**: 이미 실패 원인과 수치를 본 자료는 일반화
  성능의 독립 증거가 아니다.

## 대가

- 질의마다 관련 통계 모집단을 한 번 계산하므로 카탈로그를 순회하는 비용이 추가된다. Card의
  필드·용어 빈도와 넓은 생성 Card 여부는 카탈로그 인덱스에 캐시하되, 질의 통계는 실제로
  일치한 토큰만 작은 Map에 집계한다. 전체 빈도 Map이나 Card별 선언 토큰 Set을 세대 동안
  유지하지 않는다.
- 상대 통계 모집단의 정의, 직접 근거 경쟁과 두 순위 합의 상수는 정책의 일부다. 바뀌면 정책
  버전을 다시 올리고 보정·봉인·규모 검사를 새로 수행해야 한다.
- 의미 순위 합의는 로컬 Granite 프로필의 코사인 분포에 종속된다. 다른 프로필은 동일한 평가를
  통과하기 전까지 이 수치를 안전하다고 가정할 수 없다.
